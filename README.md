# NyayaSetu – Legal Aid & Rights Awareness Portal

A responsive, static website for a student societal project. It uses HTML, CSS and vanilla JavaScript and does not require a backend or database for the included features.

## Run locally
1. Extract the ZIP.
2. Open the `nyayasetu_legal_aid_portal` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish publicly with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `nyayasetu-portal`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The public URL will appear in the Pages settings.

## Included features
- Responsive home page and mobile navigation
- Search across rights and complaint-guide sections
- Click-to-open rights information dialogs
- Free legal aid guidance
- Official resource links and helpline information
- FAQ and legal-information disclaimer

## Important
This is an educational student project, not a government website, law firm or emergency service. Check official sources for current information. Do not collect confidential case details or sensitive personal information through this static site.
